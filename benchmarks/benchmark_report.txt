CPU Utilisation (observed during 1080p_30s run):
    Scene detection phase : ~85-95% single core (histogram computation)
    Frame write phase     : ~60-70% single core (JPEG encoding)
    Overall pipeline      : single-threaded, one core saturated
    
  Bottleneck analysis:
    480p  bottleneck: scene detection (scanning all frames)
    1080p bottleneck: pixel-level operations (resize + histogram) on larger frames
    
  Proposed optimisation:
    Parallelise scene detection and frame extraction using multiprocessing.
    GPU-accelerated resize via cv2.cuda would reduce 1080p time significantly.
